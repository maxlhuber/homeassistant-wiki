# Haus-Wiki

Vollautomatisches Home-Assistant-Wiki für HAOS. Die App liest ausschließlich das neueste vollständige Backup, entfernt Geheimnisse, erzeugt lokal ein statisches Wiki und kann größere Änderungen mit dem offiziellen Codex-CLI verständlich formulieren.

Unterstützt werden `amd64` und `aarch64`. Das erzeugte Wiki bleibt lokal und wird nie nach GitHub übertragen.
