# Schnellhilfe

Hier beginnen, wenn etwas nicht wie erwartet funktioniert.

## Erste Prüfung

1. Besteht eine unmittelbare Gefahr? Dann zuerst entsprechend handeln.
2. Funktioniert nur ein Gerät nicht oder das ganze Smart Home?
3. Lässt sich das Gerät über seinen normalen Schalter bedienen?
4. Ist Home Assistant auf Smartphone oder Computer erreichbar?
5. Zeitpunkt und sichtbare Fehlermeldung notieren.
