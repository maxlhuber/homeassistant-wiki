# Energie, Aktivität, Verlauf und Kalender

Diese Seiten werden von Home Assistant bereitgestellt und stehen in der Seitenleiste neben den eigenen Dashboards.

## Energie

<div class="annotated-image">
  <img src="../../assets/images/home-assistant/18-energie.png" alt="Energie-Dashboard von Home Assistant">
  <span class="callout-marker" style="--x:50%;--y:28%" aria-label="Markierung 1">1</span>
</div>

<ol class="step-legend">
  <li>Zeitraum und Diagramme zeigen Bezug, Einspeisung und Verbrauch. Kurzfristige Messunterschiede können durch verzögerte Statistik entstehen.</li>
</ol>

## Verlauf

<div class="annotated-image">
  <img src="../../assets/images/home-assistant/19-verlauf.png" alt="Verlaufsseite von Home Assistant">
  <span class="callout-marker" style="--x:50%;--y:18%" aria-label="Markierung 1">1</span>
</div>

<ol class="step-legend">
  <li>Hier lässt sich nachsehen, wann sich ein Licht, Sensor oder Gerät geändert hat. Das ist hilfreich bei „Warum war das Licht an?“.</li>
</ol>

## Aktivität

<div class="annotated-image">
  <img src="../../assets/images/home-assistant/20-aktivitaet.png" alt="Aktivitätsprotokoll von Home Assistant">
  <span class="callout-marker" style="--x:50%;--y:30%" aria-label="Markierung 1">1</span>
</div>

<ol class="step-legend">
  <li>Die Aktivität zeigt Ereignisse und häufig auch, ob eine Automation, ein Benutzer oder ein Gerät die Änderung ausgelöst hat.</li>
</ol>

## Kalender

<div class="annotated-image">
  <img src="../../assets/images/home-assistant/21-kalender.png" alt="Kalenderseite von Home Assistant">
  <span class="callout-marker" style="--x:50%;--y:28%" aria-label="Markierung 1">1</span>
</div>

<ol class="step-legend">
  <li>Der Kalender sammelt eingebundene Termine. Ein sichtbarer Termin bedeutet nicht automatisch, dass eine Smart-Home-Aktion daran gekoppelt ist.</li>
</ol>
