# Unsere Home-Assistant-Dashboards

Ein Dashboard ist eine zusammengestellte Bedienoberfläche. Anzeigen verändern nichts; Schalter, Tasten und Regler führen dagegen sofort die beschriftete Aktion aus. Das Öffnen eines Dashboards ändert weder Geräte noch Automationen.

| Dashboard | Für wen? | Zweck |
|---|---|---|
| [Übersicht](uebersicht.md) | Max und Meike | Alltag, Räume, Wetter, Türen/Fenster, Hausgeräte, Strom und Wallbox |
| [Cupra Laden](cupra-laden.md) | Max und Meike | Ladesitzungen, Energieanteile und Kosten |
| [Karte](karte.md) | Max und Meike | Standortanzeige von Max und Meike |
| [Systemstatus](systemstatus.md) | hauptsächlich Max | Technischer Zustand und Diagnose |
| Dashboard (Test) | nur Max | versteckte Testfläche ohne Alltagsbedeutung |

In der Seitenleiste stehen zusätzlich Home-Assistant-eigene Seiten wie [Energie, Aktivität, Verlauf und Kalender](weitere-seiten.md).

**Cupra Laden** ist die ausführliche Fahrzeugauswertung. **Systemstatus** ist eine technische Kontrollseite für Max und steuert im Normalfall nichts.
