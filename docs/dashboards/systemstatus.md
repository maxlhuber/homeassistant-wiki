# Dashboard „Systemstatus“

Der Systemstatus ist eine technische Beobachtungsseite für Max. Meike kann hier gefahrlos nachsehen. Die verwendete HAGHS-Auswertung fasst viele Prüfwerte zu Gesundheitswerten zusammen; sie ist ein Hinweis für die Fehlersuche, kein sicherer Beweis für einen Defekt.

<ol class="step-legend">

  <li>Niedrige Werte oder Warnfarben zeigen, wo Max zuerst genauer nachsehen sollte. Ein einzelner Wert ist noch kein Beweis für einen Defekt.</li>
</ol>

<div class="annotated-image">
  <img src="../../assets/images/home-assistant/12-systemstatus-diagnose.png" alt="Diagnoseansicht des Systemstatus">
  <span class="callout-marker" style="--x:50%;--y:20%" aria-label="Markierung 1">1</span>

<ol class="step-legend">
  <li>Die Rohdatenansicht zeigt einzelne HAGHS-Sensoren und ihre aktuellen Attribute. Sie ist für Max zur genaueren Diagnose gedacht. Für eine Fehlermeldung reichen meist Screenshot, Uhrzeit und betroffener Raum.</li>
</ol>

Nichts auf dieser Seite muss im Alltag „repariert“ werden. Bei mehreren roten oder nicht verfügbaren Einträgen die [Schnellhilfe](../schnellhilfe/index.md) verwenden.
