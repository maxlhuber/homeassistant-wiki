# Haus-Wiki

Diese lokale Home-Assistant-App stellt das Wiki des Raspberry Pi ausschließlich
über Home Assistant Ingress bereit.

- Ziel im Heimnetz: `http://192.168.1.189`
- Zugriff von unterwegs: über die bestehende Home-Assistant-Cloud-Verbindung
- Anmeldung: das jeweilige Home-Assistant-Benutzerkonto
- Sichtbarkeit: auch für normale Benutzer, nicht nur für Administratoren
- Direkte öffentliche Freigabe des Raspberry Pi: keine

Wenn der Raspberry Pi nicht erreichbar ist, zeigt die App eine verständliche
Fehlerseite. Home Assistant selbst bleibt davon unberührt.
